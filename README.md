# Интерактивная викторина

Простой учебный проект на HTML, CSS и JavaScript.

## Что есть в проекте

- 10 лёгких вопросов
- варианты ответов в виде кнопок
- прогресс-бар
- подсветка правильного ответа зелёным цветом
- подсветка неправильного ответа красным цветом
- подсчёт баллов
- экран результата
- кнопка «Начать заново»

## Структура проекта

```text
quiz-project/
  index.html
  css/
    style.css
  js/
    main.js
  README.md
```

## Как запустить

Откройте файл `index.html` в браузере.

## Технологии

- HTML
- CSS
- JavaScript
